## 🚀 Configuração do Ambiente

### 1. Clonar o repositório

```bash
git clone https://github.com/FreelaConnect/freela-connect-dsc-2026-01.git
cd freela-connect-dsc-2026-01
```

### 2. Instalar dependências

```bash
npm install
```

### 3. Executar o projeto

```bash
npm run start
```

## 🌿 Fluxo de Trabalho (Git)

Padrão adotado pela equipe:

* `main` → versão estável
* `develop` → integração de funcionalidades
* `feature/*` → desenvolvimento de novas funcionalidades

### Exemplo:

```bash
git checkout -b feature/cadastro-usuario
```

---

## 🧾 Padrão de Commits

Utilizar prefixos para organização:

* `feat:` nova funcionalidade
* `fix:` correção de erro
* `docs:` documentação
* `chore:` ajustes gerais

### Exemplo:

```bash
git commit -m "feat: implementa cadastro de usuário"
```
