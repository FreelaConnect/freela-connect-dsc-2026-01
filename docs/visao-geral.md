# Visão Geral do Sistema — Freela Connect

## 1. Introdução

O crescimento das plataformas digitais tem ampliado o uso do trabalho freelancer, permitindo que profissionais ofereçam serviços de forma mais flexível e que clientes encontrem soluções sob demanda.

Nesse contexto, o **Freela Connect** é uma plataforma proposta para conectar clientes e freelancers, facilitando o processo de contratação e gestão de serviços.

---

## 2. Problema

Atualmente, a contratação de freelancers apresenta alguns desafios, como:

* Dificuldade em encontrar profissionais qualificados
* Falta de confiança entre cliente e freelancer
* Comunicação ineficiente
* Ausência de um processo organizado de contratação

Esses problemas tornam o processo mais complexo e menos seguro.

---

## 3. Solução Proposta

O sistema **Freela Connect** propõe uma plataforma digital que permite:

* Cadastro de usuários (clientes e freelancers)
* Publicação de projetos
* Envio de propostas
* Comunicação entre usuários
* Avaliação dos serviços prestados

A proposta é tornar o processo mais simples, organizado e confiável.

---

## 4. Objetivo

### Objetivo Geral

Desenvolver uma plataforma que facilite a conexão entre clientes e freelancers.

### Objetivos Específicos

* Permitir o cadastro e gerenciamento de usuários
* Facilitar a publicação de projetos
* Organizar o envio de propostas
* Criar um sistema de avaliação
* Melhorar a comunicação entre as partes

---

## 5. Público-Alvo

O sistema será utilizado por:

* **Clientes:** que desejam contratar serviços
* **Freelancers:** que oferecem serviços
* **Administradores:** responsáveis pela gestão da plataforma

---

## 6. Escopo

### Inclui:

* Cadastro de usuários
* Publicação de projetos
* Envio de propostas
* Sistema de avaliação

### Não inclui (versão inicial):

* Sistema de pagamento
* Aplicativo mobile nativo

---

## 7. Visão Geral do Sistema

O sistema será estruturado em três partes principais:

* **Frontend:** interface do usuário
* **Backend:** regras de negócio
* **Banco de Dados:** armazenamento das informações

Tecnologias previstas:

* Node.js (backend)
* React / React Native (frontend)
* PostgreSQL (banco de dados)

---

## 8. Resultados Esperados

Espera-se que o sistema:

* Facilite a contratação de freelancers
* Organize o processo de prestação de serviços
* Aumente a confiança entre os usuários
* Sirva como base para futuras melhorias

---

## 9. Considerações Finais

O **Freela Connect** busca oferecer uma solução simples e eficiente para intermediar serviços freelance, contribuindo tanto para o mercado quanto para o desenvolvimento acadêmico do projeto.
